# Velious gem sources

Gems for **Thurgadin** / **Kael** / **Skyshrine** class armor (and the same gem list on ToV mold lines). Each turn-in is **mold + 3 identical gems**. Molds come from Kael giants / veterans (Thurgadin), ToV west (Kael armor), or ToV east (Skyshrine) — see [Quest Gear](Quest-Gear.md) and [Velious Factions](Velious-Factions.md).

**IdleQuest** drop truth below (`velketor`, `sirens`, `necropolis`, `cobaltscar`, `wakening`, `thurgadinb`, `skyshrine`, …). Save every useful gem; vendor junk (Crushed Diamond Dust, Crushed Nephrite, chipped jewelry chips, …) is called out at the bottom.
