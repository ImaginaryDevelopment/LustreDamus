# Quest gear — loot to turn in

Classic / Kunark / Velious. Field drops and molds that become **worn gear**. Not keys, not faction-only (goblin ears, gnoll scalps), not full epic walkthroughs.

**Cracked Paineel Shield** is **not** an upgrade quest. Hole drop (revenant / wanderer / temple researcher). MAGIC, AC **2**, secondary. WAR CLR PAL RNG SHD **MNK** BRD ROG SHM. Monks loot it for the **skull graphic**. There is no turn-in.
