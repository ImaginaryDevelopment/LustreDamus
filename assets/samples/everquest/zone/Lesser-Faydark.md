# Lesser Faydark — unique loot

Classic outdoor (`lfaydark`). Unmodified XP (**1.00×**). Hunt **~8–40** (orc / pixie / brownie → unicorn / Teir`Dal). Wooded zone between Greater Faydark, Steamfont, and Butcherblock approaches. Brownie / faerie / unicorn / bandit camps; several epic-adjacent nameds.

**Faction / LEAVE warning:** Wood-elf / brownie friendlies and epic NPCs (Gearheart sprockets, Equestrielle horn, Princess Joleena wing) are easy mistakes. Tag quest / epic NPCs **LEAVE** until you need the drop.

**IdleQuest** spawn/loot truth: [brynnb/idlequest-content](https://github.com/brynnb/idlequest-content) (`lfaydark`). Skip joke / trigger rows (`Trigger`, Taskmaster Mirot mega-HP stub).
