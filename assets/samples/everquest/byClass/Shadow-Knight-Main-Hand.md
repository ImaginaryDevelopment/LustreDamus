# Shadow Knight — groupable main hand

Classic / Kunark / Velious. **1H Slashing + shield** is the default tank setup; strong **2H Slashing** is listed when it is a real SK chase (Gravebinder, Iceflame, Fatecaller). **Group camps only** — no Trakanon, Vox, VP dragons, ToV, Tunare, Tormax, Yelinak, Wuoshi, or Sleeper. NO DROP is fine.

Sort by **Item** or **DMG**. Filter also matches zone / camp.

**Rule of thumb:** chase **Sword of Pain** (Velketor) as the best groupable 1HS before epic; **Gravebinder** / **Iceflame** / **Fatecaller** if you want raw 2HS damage. End goal is **Innoruuk's Curse**.
